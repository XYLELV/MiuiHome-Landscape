# 小米 11T Pro 真机验收清单

测试前记录系统版本、MIUI Home versionCode、LSPosed 版本与模块构建哈希。先备份桌面布局，并保持 USB 调试可用。

## 1. 启动与回退

- 设置页能收到带 nonce 的桌面 ACK，显示兼容门禁通过。
- 竖屏桌面、负一屏、文件夹、编辑模式与手势和未启用模块时一致。
- 横置后只出现一个横屏 Overlay，无黑屏、双层图标或触摸穿透。
- 横屏转竖屏、熄屏/亮屏、锁屏解锁、主题切换后原生状态恢复。
- 关闭 LSPosed 模块并重启桌面后，MIUI 原桌面完整可用。

## 2. Grid 与 Dock

- 每页严格 8×3，点击命中、长按源位置与视觉格一致。
- 左右滑页可吸附；拖到边缘需明确停留才翻页。
- Grid 空槽移动、两应用建文件夹、两个位置交换、插入右移均正确。
- Dock 9 个槽位可点击和拖放；Grid↔Dock 交换不产生重复或丢失。
- 工作资料应用使用正确 Profile 启动。
- 长按 Grid/桌面空白处按系统标准时长进入全局编辑，Grid 与 Dock 同时显示移除按钮。
- 编辑中连续拖动多个图标不会自动退出；“添加应用”保持编辑状态，“完成”或点击空白处退出。
- Grid/Dock 移除均有确认提示，只改横屏布局；竖屏桌面和已安装应用保持不变。
- 全局编辑不出现顶部工具栏，点击空白退出后所有移除按钮消失。

## 2A. 液态玻璃设置 App

- 竖屏为单列滚动；横屏为左右双栏，两栏可独立滚动且不被状态栏、导航栏或刘海遮挡。
- 蓝白动态背景、玻璃卡片、按钮和开关在浅色内容上仍有清晰对比度，无白字白底。
- “添加应用”列表包含图标、名称、包名与开关；搜索名称和包名均可命中。
- 应用开关打开后出现在横屏 Grid；关闭后能从 Grid、Dock、文件夹中移除并正确折叠两成员文件夹。
- 快速连续切换不同应用不会丢失提交；桌面无响应时开关恢复同步而不是永久转圈。
- Dock 关闭后网格使用释放空间；重新打开、切换玻璃材质和透明度后立即生效并可持久化。

## 3. 文件夹

- 文件夹打开时仍在同一 Launcher Window，没有新 Window 闪烁。
- 文件夹内排序、改名、添加应用正确。
- 成员拖到 Grid 空槽、普通应用、另一文件夹和 Dock 均正确。
- 两成员文件夹移出一项后，剩余应用提升回原 Grid 位置。
- 大文件夹可滚动，边缘和刘海侧不被裁切。

## 4. 后台任务

- 慢上滑、快速上滑、从应用回后台、旋转中进入后台均不出现空白任务页。
- 慢上滑过程中不闪出 MIUI 原生竖版任务卡；点击单卡关闭按钮后仍停留在横屏后台。
- 点击单卡关闭后目标 taskId 从最近任务消失，应用由 MIUI 原生清理链处理，界面不会退到纯背景。
- 清空后台、返回横屏主页后再旋转为竖屏，必须显示竖屏首页而不是竖屏后台。
- 上滑半程只显示 MIUI 的原生过渡；完成手势后再接管，不出现“横版→原生→竖版”三段跳。
- 卡片点击只启动一次；关闭单项只移除一次；清空只执行一次。
- 后台数据为空、反射失败或 3 秒超时时，原生 MIUI 后台保持可见。
- Launcher pause/resume 后重新读取原生 `RecentsContainer` 可见性，不复用旧 epoch。
- 后台显示时重建 Launcher Activity，不出现“桌面和后台同时隐藏”。

## 5. 压力与数据

- 至少导入 200 个应用，连续翻页、旋转和拖放 10 分钟，无 ANR。
- 连续执行 100 次 Grid/Dock/Folder 操作后，重启桌面，布局与退出前一致。
- 主快照故意损坏但备份正常：加载备份且不清空。
- 主/备份都损坏：显示保护提示、恢复 MIUI 原生桌面、普通操作不覆盖；只有明确重置后恢复。
- 安装/卸载应用、移除工作资料后，不崩溃；失效图标不会破坏其余布局。

## 6. 日志与故障恢复

```sh
adb logcat -v threadtime | grep -E "MIHL5|MIHL/Recents|MIHL.Store|Xposed"
adb shell am force-stop com.miui.home
```

遇到可复现故障时保留：操作步骤、横竖屏状态、日志、屏幕录像、MIUI Home versionCode 与布局 revision。
